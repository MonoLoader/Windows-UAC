# GitHub repository setup

## Repository name

Windows-UAC-Research-Catalog

## Description

A curated reference to 10 GitHub repositories covering Windows UAC research, remote administration, DLL injection, and security analysis, with source links, original topics, and practical review guidance.

## Topics

windows-security uac user-account-control security-research cybersecurity privilege-escalation dll-injection remote-administration security-analysis github-catalog defensive-security research-resources

## Upload checklist

1. Create a new GitHub repository with the name above.
2. Extract the ZIP archive locally.
3. Upload the CONTENTS of the Windows-UAC-Research-Catalog folder to the repository root. Do not upload only the ZIP or nest the entire folder.
4. Include the hidden .github directory. If uploading through a browser does not preserve it, use Git or GitHub Desktop.
5. Commit the uploaded files. README.md should render on the repository home page.
6. Open the settings icon next to About and enter the Description and Topics above. These are not populated automatically from files.
7. Review all links and choose a license before inviting reuse of your original content.

## Tracking links

The README preserves the requested red/black badge style and the example attribution values utm_source=github, utm_acc=HydraSoft, and utm_name=Windows-UAC-Research-Catalog on the original search link. HydraSoft is an example supplied in the conversation, not a verified owner identity. Change or remove utm_acc before publishing if it does not identify your account. GitHub is not guaranteed to report these parameters as analytics. No link redirects to an unrelated download site.

## What this package is

A documentation catalog, not a combined Windows utility. It has no application code, binaries, installer, deployment, or Git history. An online repository has not been created by preparing this archive.
