# Contributing

This repository maintains a reference catalog, not a collection of executable tools.

## Corrections

Open an issue using the appropriate form. Include the repository URL, the incorrect field, and a public source supporting the correction. Do not include credentials, private data, or executable attachments.

## Pull requests

- Keep the README in English.
- Update README.md and the corresponding entries in data/ together.
- Preserve original Description and Topic spellings when quoting the source. Keep authored summaries separate.
- Record missing Topics as an empty JSON array, not invented labels.
- Attribute compatibility and detection claims to the author unless independently verified and documented.
- Link directly to the source. Do not add misleading download badges, affiliate redirects, binaries, payloads, or operational attack instructions.
- Do not replace this historical snapshot silently with a different search result set; explain any scope change.

Licensing of original catalog material has not yet been selected. See LICENSING.md before submitting material for redistribution.
